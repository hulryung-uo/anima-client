# Anima v0.7.0 — Your worlds, ready to return to

This draft brings saved worlds, account profiles and guided setup to the desktop
client. It is being prepared for installation testing; it is not yet a public
release or a claim that the full client-readiness audit is complete.

## Return to your worlds

- Save several servers and keep a separate account list for each one.
- Optionally remember passwords in macOS Keychain or Windows Credential Manager.
  Passwords never go into profile JSON or browser storage.
- See cached reachability, response time and supported public server details
  beside the login form, with the last check time visible.
- Preview the character names cached at the last authentication, then log in to
  receive the current character list before entering the world.
- Cancel an in-progress connection. Connection deadlines and interruption
  recovery keep failed attempts from leaving the login screen stuck.

## Set up and keep your preferences

- First launch checks your own Ultima Online game files, explains missing files
  and lets you choose a supported folder. Game data is not included.
- Change the game-file folder for the next launch without editing JSON by hand.
- Recover unreadable desktop settings while retaining the original file.
- Renderer settings validate stored values and keep unsaved changes in memory
  when browser storage fails. A settings backup/recovery screen is included.
- Failed profile-file or vault operations attempt to restore the previous saved
  passwords. Recovery failures show an actionable message.

## Validation and remaining checks

The source has passed Rust, WASM and web checks, macOS/Windows desktop tests and
saved-profile failure regressions. An isolated macOS Keychain/profile lifecycle
test also passed. These do not replace installed-app runtime checks.

Before public release, the current installers still need installation and launch
checks, actual settings-file export/import, Windows credential-vault behavior,
and current-build live-server gameplay verification. The local ServUO instance
was offline during the recent UI work. See the ongoing
[client-readiness audit](https://github.com/hulryung-uo/anima-client/blob/main/docs/CLIENT_READINESS.md).

The macOS download targets **Apple Silicon**. Intel Macs need a separate Intel
or universal build. The Windows download targets x64 and uses the NSIS installer.
Bring your own compatible UO data files and game-server account.
