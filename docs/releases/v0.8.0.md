# Anima v0.8.0 — Keep your worlds, carry your settings

This testing draft adds portable backups and improves recovery when connections
or asset loading fail. It builds on v0.7.0's saved servers, per-server accounts,
optional OS password storage and guided game-file setup.

## Take your setup with you

- Export your servers, notes and account names, then preview and add them on
  another device. Importing keeps existing profiles and avoids duplicates.
  Passwords and cached character/server details are excluded.
- Recover unreadable server profiles while keeping an exact copy of the original
  file. Existing OS-vault passwords remain untouched during profile recovery.
- Back up and restore window positions and sizes alongside options, macros,
  map markers and other renderer preferences. Review a backup before applying
  it, or return to the previous settings copy.

## Smoother recovery and longer sessions

- Changing game connections clears the previous world's input and character
  selection state, including when servers reuse the same character number.
- Muting or losing a connection cancels delayed sound playback. Sound-bank reads
  and decoded-sound caches now use bounded retention and loading work.
- Graphics caches reclaim unused images by count and estimated pixel size while
  protecting displayed characters, clothing and house previews. Images cannot
  be reused while they are being released.
- Temporary image or animation-info failures retry instead of leaving permanent
  gaps. Click masks are released with the art they belong to.

## Testing status

The feature source passed all Linux, macOS and Windows quality jobs. An isolated
macOS build verified native file selection, profile recovery with an exact
original copy, a two-server/three-account import and export, duplicate-free
reimport, settings-file restore/export, and restoration of the previous settings
copy. Chrome separately verified real PNG loading, cache eviction/reload, precise
pixel hits and recovery after temporary HTTP failures.

These are source-build checks. Installer build/signature/install results are
recorded separately in the draft's manifests and verification record when they
finish. The actual installers still need interactive testing on both platforms,
and the current build needs live-server gameplay/disconnect/re-entry checks.
The local ServUO instance was offline during this work and was not started.
The broader [readiness audit](https://github.com/hulryung-uo/anima-client/blob/main/docs/CLIENT_READINESS.md)
remains open; this draft is not a public release announcement.

The macOS installer targets **Apple Silicon**; Windows targets **x64**. Game data
is not bundled. Bring compatible Ultima Online client files and your own server
account. Password storage protects saved passwords on the device; it does not
change the game's existing network protocol.
