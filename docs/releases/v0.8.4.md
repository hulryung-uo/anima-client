# Anima v0.8.4 — Windows launch and login reliability

This preview brings the current desktop client to Apple Silicon macOS and
Windows x64. Supply your existing Ultima Online game data; no game data is
included in these installers.

## Changes

- Windows release builds launch as a GUI application without opening an extra
  console window. Installer checks now verify this in the installed executable.
- Login errors follow the server and account that actually failed. Changing
  the destination or account hides the old error; a new failure remains visible.
- Choose a saved server, enter your account/password and connect. Supporting
  shards can create accounts through that ordinary login request. New or changed
  local profiles offer Save & connect or Connect without saving; saving the
  password is a separate desktop-only choice using the operating system vault.
- Includes the preceding preview improvements: multiple saved servers/accounts,
  cached server and character information, settings/worlds backups and recovery,
  per-character window positions/sizes, keyboard fixes and bounded graphics caches.

## Verification and limits

The full local quality gate passed: native, WASM, desktop and tooling checks,
plus 374 renderer tests with 1,867 assertions. Source CI also passed on Linux,
macOS and Windows. Release build and installer checks run against this exact tag;
installer hashes and signing details are in the attached manifests.

The preceding v0.8.3 Windows installer was freshly installed in a Windows 11
ARM64 Parallels VM, accepted read-only shared UO data, and connected to live
ServUO. Anima QA entered Britain with visible terrain, character, status and
journal; the user confirmed the screen. Windows x64 code runs under emulation
in that environment. Source-runtime checks also covered character creation,
movement, opening a backpack, logout and re-entry with a new session ID.
These observations are not a claim that all gameplay or the new installer has
already been tested. Current v0.8.4 installer acceptance is recorded in the
[readiness audit](https://github.com/hulryung-uo/anima-client/blob/main/docs/CLIENT_READINESS.md).

This is a prerelease. Sustained sessions, broader combat/casting/inventory flows,
character-layout switching in installed apps and native x64 Windows runtime
coverage remain incomplete. Windows installers are currently unsigned. The
macOS download targets Apple Silicon; Intel Macs need a separate build.
