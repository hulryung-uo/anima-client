# Anima v0.8.2 — More reliable maps and lighting

This testing draft includes the simpler account-name/password login and optional
local saving from v0.8.1, plus the following reliability fixes.

- Switching game-data folders no longer reuses another installation's cached
  world map. Changed source-file metadata or a damaged cache triggers a rebuild.
  Simultaneous clients can write their caches without sharing temporary files.
- Torch and spell light masks recover after temporary image-loading failures.
  Stalled loads time out, retries back off, and unused colour variants are
  released. The normal radial light remains available while a mask is missing.
- Native light-file reads validate image sizes and file ranges before allocating
  pixel buffers. Custom masks exceeding 4,194,304 pixels are refused, matching
  the renderer's 16 MiB RGBA per-image ceiling.
- In browser mode, a one-time login with another username or relay cannot put its
  characters into the previously selected account's cache. Character updates
  preserve concurrent profile edits and do not overwrite damaged profile data.

## Testing status

The full local quality gate passed, including renderer, tooling, native, WASM
and desktop checks. Native regressions cover cache corruption, source changes,
concurrent writes and malformed light files. Both real-resource light tests
passed; the local stock data contains 55 valid masks, all within the size limit.
A loopback HTTP test also verifies that one-time credentials do not overwrite
saved passwords or borrow a password from another endpoint.

These results verify source behavior. This version's installer build, signing
and installation results are recorded in its manifests and workflow. Installed
app interaction, live-shard gameplay, disconnect/re-entry and long-session
verification remain open. The earlier v0.8.1 Mac installer reached the real login
screen, but subsequent UI checks were interrupted and are not claimed complete.
See the [readiness audit](https://github.com/hulryung-uo/anima-client/blob/main/docs/CLIENT_READINESS.md).

Downloads target Apple Silicon macOS and Windows x64. Game data is not bundled;
use compatible Ultima Online client files and your own shard account. This is a
testing draft, not a public release announcement.
